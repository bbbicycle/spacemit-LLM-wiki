# 代际隔离与模型性能核实

涉及芯片、板卡规格或模型能力时读取。本文件定义核实方法，数值以当前证据及其适用版本为准。

- 明确区分 K1 与 K3、Muse Pi 与 Muse Pi Pro 等具体产品。芯片支持某接口不代表每块板卡均引出该接口。
- 先取相应事实表或专题，再引用 CPU 架构、内存容量/位宽、TOPS、功耗和接口数量；不使用“Spacemit 芯片”泛称归属某代专有规格。
- 引用 30B 等规模时说明模型名、Dense/MoE、总参数和实际激活参数。MoE 激活参数不能代替完整权重的存储需求。
- 性能数字需附模型、量化/精度、设备内存、SDK/运行时版本和实测条件。分开描述首词延迟、生成速度和吞吐，不将单项实测推广为所有配置的保证。
- 模型上限不是只由 TOPS 决定；缺少内存、精度或实测证据时说明尚未验证，不把示例范围写成永久硬上限。

优先查询 `k1_ai_performance_data`、`k3_ai_performance_data`、相关产品规格与模型推理专题。文档过期或冲突时定向核实上游，并在回答中说明状态。
