# Hardware Safety & Physical Debugging Guardrails

硬件电路设计、PCB 走线与物理接口调试的绝对安全红线。违反以下规则可能导致芯片物理烧毁、电源漏电或调试器永久死锁。

---

## 1. JTAG 排线反接避坑 (K1 vs K3 差异)

官方 TF 卡扩展调试子板上的牛角座核心引脚定义在两代芯片上**完全相反**。

**Incorrect:**
```text
# 错误做法：直接将 K1 调试器的 TDI/TMS 线序插入 K3 开发套件 (如 CoM260)
J-Link Pin 5 (TDI)  -------->  K3 牛角座 Pin 5
J-Link Pin 7 (TMS)  -------->  K3 牛角座 Pin 7
# 结果：JTAG 信号物理反转，J-Link 扫描超时，芯片无法挂接并进入死锁状态！
```

**Correct:**
```text
# 正确做法：牢记代际引脚定义差异，K3/CoM260 必须做交叉反接
【K1 系列】: Pin 5 = TDI,  Pin 7 = TMS  (直连)
【K3 系列】: Pin 5 = TMS,  Pin 7 = TDI  (物理反转！)

J-Link TDI (Pin 5)  -------->  K3 牛角座 Pin 7 (TDI)  [交叉接线]
J-Link TMS (Pin 7)  -------->  K3 牛角座 Pin 5 (TMS)  [交叉接线]
J-Link TDO (Pin 13) ------->  K3 牛角座 Pin 13 (TDO) [直连接线]
```

## 2. Strap 引脚上拉阻抗 (严禁直接短接)

K1/K3 芯片在复位释放瞬间采样 Strap 引脚以决定启动介质与工作电压。系统启动完成后，这些管脚会动态复用为 QSPI 高速数据线或普通 GPIO。

**Incorrect:**
```text
# 错误做法：为了固定引导模式为 1，将 Strap 引脚直接用导线或 0Ω 电阻焊接至 3.3V/1.8V 电源或 GND
Strap Pin  ───────────────  VCC33_GPIO (直接短接)
# 结果：上电复位完成后引脚翻转输出低电平时，形成电源对地死短路，瞬间烧毁主控 IO 驱动器！
```

**Correct:**
```text
# 正确做法：配置为 0 利用内部弱下拉悬空；配置为 1 必须串联 4.7kΩ ~ 10kΩ 隔离电阻
配置为 0 (默认):
Strap Pin  ───────────────  NC (悬空即可，利用芯片内部弱下拉)

配置为 1:
Strap Pin  ───────[ 4.7kΩ ~ 10kΩ 电阻 ]───────  VCC_IO
```

## 3. 闲置外设电源域必须供电 (严禁悬空)

在不需要 HDMI、PCIe、MIPI CSI/DSI、eMMC 或 USB2.0 的单板设计中。

**Incorrect:**
```text
# 错误做法：以为外设不用就可以不供电以节省功耗或布线空间
VDD18_HDMI  ───────────────  NC (断电悬空)
VDD33_USB   ───────────────  NC (断电悬空)
# 结果：引起 SoC 内部寄生回路漏电、异常发热，甚至导致全局掉电保护复位。
```

**Correct:**
```text
# 正确做法：即使项目中完全不用某外设，其对应的芯片引脚电源域也必须完整正常供电
VDD18_HDMI  ───────────────  正常接入 1.8V 稳压输出
VDD33_USB   ───────────────  正常接入 3.3V 稳压输出
```

## 4. 模拟 PHY 供电磁珠不可省略

PLL、Audio、CSI/DSI、HDMI 等模拟 PHY 供电电路。

**Incorrect:**
```text
# 错误做法：为节省 BOM 成本将滤波磁珠替换为 0Ω 电阻或直接铜皮相连
数字电源 VDD18  ──────────[ 0Ω 电阻 / 铜皮 ]──────────  模拟供电 AVDD18
# 结果：数字高频开关噪声窜入模拟锁相环，引起时钟抖动、高速接口眼图恶化、外设初始化随机失败。
```

**Correct:**
```text
# 正确做法：必须严格保留推荐规格的滤波磁珠隔离高频杂讯
数字电源 VDD18  ───────[ 磁珠 120Ω@100MHz ]───────  模拟供电 AVDD18 (并联 100nF 去耦电容)
```
