# SpacemiT Wiki Skill

稳定的检索行为契约 v1：优先查询 MCP，确认芯片/板型/版本，按需读取精炼知识与固定版本原文，保留来源、状态与授权边界。

按 [安装指南](https://github.com/bbbicycle/spacemit-LLM-wiki/blob/main/INSTALL.md) 和 [安装清单](https://github.com/bbbicycle/spacemit-LLM-wiki/blob/main/install/manifest.json) 安装本目录的全部文件；MCP 连接另行配置，服务地址以清单为准。

- [SKILL.md](SKILL.md)：触发范围、检索漏斗、证据纪律与只读边界。
- [mcp.md](mcp.md)：按需查看接入和工具参数。

知识与版本状态由服务提供；知识更新或服务迁移无需修改本契约的行为规则。协议或行为变化另行版本化。
