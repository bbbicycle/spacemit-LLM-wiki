# K1 芯片开发快速上手向导

适用于 K1 及对应板卡。先确认板型、内存、系统和 SDK 版本，再沿下列步骤开展开发。

## 1. 确认规格和供电条件

阅读 [K1 产品简介](../Sources/docs-chip/zh/key_stone/k1/k1_docs/root_overview.md)：8 核 X60、RVA22 与 RVV 1.0；不要套用 K3 的 X100/A100 或模型规模。供电、功耗与散热参考 [[Knowledge_Atoms/K1热设计与功耗专题档案]] 和 [[Evidence/k1_thermal_specs]]，保留其未核验项和测量条件，不用单一历史 TDP 推定散热器。

## 2. 核对启动与烧录配置

按 [K1 硬件设计指南 1.1.5](../Sources/docs-chip/zh/key_stone/k1/k1_hw/k1_hw_design_guide.md) 与对应板型原理图核对 Strap。QSPI_DATA3/Strap3 为 Boot/Download：0 启动、1 下载；板上拨码与芯片电平不是同一种编号。配置前读 [[Knowledge_Atoms/K1启动模式与Strap管脚配置专题档案]] 和 [[Evidence/k1_strap_pins_config]]，核对 IO 电压和复用条件。

## 3. 按用途选择 SDK

[K1 SDK 概览](../Sources/docs-chip/zh/key_stone/k1/k1_sw/k1_sdk_user_guide.md) 分别提供 Buildroot（定制嵌入式）、OpenWrt（软路由/NAS）、Bianbu（通用 Linux）、K1 OH5.0 和 AI Robot。源码分支、构建与烧录按所选 SDK 的指南执行，不能把一种系统的命令用于另一种系统。

## 4. 先跑通固定模型，再测性能

读 [[Knowledge_Atoms/K1大模型本地推理与AI算力专题档案]] 与 [[Evidence/k1_ai_performance_data]]。当前固定 [Llama.cpp 指南](../Sources/docs-ai/zh/compute_stack/ai_compute_stack/llama.cpp.md) 为 K1 推荐 Qwen3-0.6B GGUF；Bianbu 包安装入口为：

```bash
sudo apt update
sudo apt install llama.cpp-tools-spacemit
```

旧固件未提供此包时，原文另列 `llama-server` 路径，先确认实际仓库版本。下载指南中的模型，按其 K1 线程条件（不超过 4）和本机 `--help` 运行、记录内存与生成速度。ONNX 视觉模型与 GGUF LLM 使用不同路径，不能将 ONNX 编译流程一概用于大语言模型，也不承诺任意配置均超过 10 tokens/s。
