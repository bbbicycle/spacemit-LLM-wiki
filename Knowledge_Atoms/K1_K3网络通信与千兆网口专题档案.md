# K1/K3 网络通信与千兆网口专题档案

> [!TIP]
> **💡 工程师导读与排坑焦点**：指导双 GMAC 千兆网口电路、百兆 PHY 兼容避坑、无线 SDIO 联调、K3 GMAC DPDK 用户态旁路与 EtherCAT 工业实时总线驱动热切换。
> **目标读者**：`硬件电路工程师 / 网口驱动 / 高性能网络工程师` | **技术领域**：`hardware_schematic_design`

本专题档案汇总了 SpacemiT K1 和 K3 芯片在双路以太网控制器（GMAC）、板级 PHY 芯片选型、无线 Wi-Fi/BT 模组接口联调、K3 GMAC DPDK 高性能网络加速方案，以及 K3 EtherCAT 工业以太网实时主站的核心规范。

---

## 1. 千兆以太网 (GMAC) 硬件选型避坑

在进行 K1 或 K3 开发板设计时，网络 PHY 芯片的选型至关重要：
*   **不支持纯百兆 PHY**：
    *   **K1 限制**：K1 FAQ 记录不支持纯百兆 PHY，即使只使用 100M 速率也需核对千兆 PHY 方案。
    *   **K3 独立核对**：K3 具有 4 个 GMAC，支持 RMII/RGMII，GMAC0/1 还支持 MII；不能将 K1 的 PHY 限制或两路 MAC 数套用到 K3。具体出处见 [[Evidence/k1_k3_network_specs]]。
*   **单网口与双网口设计**：
    *   K1 有两路 GMAC；K3 有四路。SoC 的控制器数量与开发板实际 RJ45 数量分别核对。
    *   若硬件为了控制成本或减小体积，设计为单网口产品（例如 Muse Pi 仅引出 GMAC0 对应的网口），在 BSP 软件端配置正确的设备树（DTS）后，**完全不会影响操作系统的网络功能或导致底层驱动报错**。

---

## 2. 无线模组接口联调 (Wi-Fi / BT)

*   **SDIO 3.0 通道**：用于 Wi-Fi 模组的数据传输。由于 SDIO 3.0 的高速率（最高 104MB/s），PCB 走线必须控制在 **50 Ω** 单端阻抗，且时钟线与数据线等长必须严格控制在 1mm 以内。
*   **电平匹配**：Wi-Fi 模组引脚通常工作在 1.8V 逻辑电平，若选用 3.3V 的模组，必须在 SDIO 通道上增加高速电平转换芯片，或配置芯片内对应的 `VCC1833_MMC` 电源轨。

## 3. K3 GMAC DPDK 高性能用户态数据平面加速

针对边缘网关、网络流量监测与 RISC-V 软路由等高性能数据包吞吐场景，SpacemiT 在 K3 平台提供了官方 **DPDK (Data Plane Development Kit)** 支持：

*   **架构优势（Kernel Bypass）**：传统 Linux 内核协议栈存在中断开销、多次内存复制（sk_buff）及进程上下文切换。DPDK 采用用户态轮询模式驱动（PMD），直接接管 GMAC 硬件收发队列，极大压降网络延迟。
*   **核心组件分工**：
    *   **EAL (环境抽象层)**：完成大页内存（Hugepages）分配、CPU 亲和性核心绑定与 PCIe/GMAC 硬件抽象。
    *   **Ring & Mempool**：无锁多生产者/多消费者 FIFO 队列管理数据包包头与缓冲区释放。
    *   **PMD 驱动**：K3 GMAC 轮询模式驱动直接在用户空间与网卡 DMA 交互。
*   **工程编译配置**：在 Buildroot 编译配置中启用 `BR2_PACKAGE_DPDK=y`，并在系统引导后通过驱动解绑脚本将目标 GMAC 从标准内核驱动切换至用户态框架。

## 4. K3 EtherCAT 工业以太网主站与实时总线方案

在工业自动化控制与具身关节伺服通信场景中，SpacemiT 在 K3 平台上提供了原生的 **IgH EtherCAT Master** 实时协议栈集成：

*   **核心技术指标**：
    *   **高实时性**：支持 500 µs DC 周期，满足高端工业伺服闭环控制要求。
    *   **纳秒级时钟同步**：实现小于 **1 µs** 精度的分布式时钟（Distributed Clocks, DC）同步。
    *   **协议兼容性**：全面支持 CoE (CANopen over EtherCAT)、SoE、FoE 等工业总线协议。
*   **DTS 极简配置规范**：
    *   K3 平台内核已默认开启 `EC_MASTER`、`EC_DEVICE`、`EC_K3_GMAC` 与 `EC_MASTER_OF` 支持。
    *   对于已支持的官方板型，用户**无需修改网口 compatible**，仅需在板级 DTS 中使能主站节点即可直接使用：
        ```c
        &ec_master {
            status = "okay";
        };
        ```
*   **GMAC 驱动热切换机制 (Driver Override)**：
    K3 GMAC 默认加载标准 Linux 以太网驱动，支持在系统运行状态下通过 sysfs 无缝切换至 EtherCAT 实时网卡驱动（以 `cac80000.ethernet` 为例）：
    ```bash
    # 1. 指定 EtherCAT 驱动目标
    echo dwmac-spacemit-ethqos-ethercat > /sys/bus/platform/devices/cac80000.ethernet/driver_override
    # 2. 解绑标准网络驱动
    echo cac80000.ethernet > /sys/bus/platform/drivers/dwmac-spacemit-ethqos/unbind
    # 3. 动态绑定 EtherCAT 实时驱动
    echo cac80000.ethernet > /sys/bus/platform/drivers/dwmac-spacemit-ethqos-ethercat/bind
    ```
*   **RT 实时内核支持**：为了压降内核调度抖动，官方推荐部署 `linux-image-6.18.3-rt` PREEMPT_RT 实时内核，并通过 systemd 单元服务实现开机全自动绑定 EtherCAT 驱动。
