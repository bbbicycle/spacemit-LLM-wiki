# K3 CoM260 开发套件板级硬件设计与产品特点专题档案

> [!TIP]
> **💡 工程师与架构师导读**：
> 本文系统汇总了基于 SpacemiT K3 芯片的核心计算模组 **K3 CoM260** 及其开发套件的产品定位、模组特点、12-Pin 多功能调试接口、MIPI CSI 多链路复用与屏显接口设计。

## 0. 产品定位与计算模组核心特点 (Product Profile)

### 0.1 一句话产品定位
> **K3 CoM260** 是一款专为**工业机器人、具身智能与高端嵌入式装备量产**打造的 RISC-V 核心计算模组（SoM）及开发套件。核心板高集成度封装了 60 TOPS 算力、LPDDR5 内存与电源系统，助力客户以极低成本定制专属载板。

### 0.2 三大核心杀手级特点
1. **核心计算模组与底板解耦设计 (Modular SoM Architecture)**：
   * 采用高密连接器将 K3 芯片、高频 LPDDR5、UFS 本地存储及伴随 PMIC 全部集成在核心板上。终端客户仅需根据实际工业场景设计简单的双层或四层外设载板（引出所需接口），研发周期从半年缩短至数周，量产维护成本极低。
2. **机器人全栈控制直出 (Robotics-Ready Control)**：
   * 模组不仅具备 60 TOPS AI 视觉处理能力，更将芯片内部独立的实时微控制器 **RT24** 完整引出，原生支持 **EtherCAT、CAN-FD、多路 PWM**，实现从视觉感知、多模态决策到微秒级电机伺服驱动的“大脑+小脑”单模组闭环。
3. **超灵活的多路 MIPI CSI 机器视觉复用**：
   * 载板提供 2 路 22-Pin FPC 接口，出厂支持“4+4”、“4+2+2”或四路并发图像采集，满足工业巡检、无人机避障及多目立体相机视觉算法需求。

### 0.3 选型建议：何时选 CoM260 而非单板电脑 (Pico)？
* **选 K3 CoM260**：产品形态非标（如特殊外壳、导轨安装）、需要批量量产、需要引出自定义工业接口（如多路隔离 RS485、光电隔离 DI/DO）、或对接线接口位置有严格机械限制。
* **选 K3 Pico**：需要开箱即用成品单板、追求极简单线 Type-C 供电、或需要板载万兆光口进行大带宽组网。

## 1. 12-Pin 多功能按键与调试接口

K3 CoM260 参考载板上设计了一个高集成度的 **12-Pin 调试与控制排针**，汇总了状态显示、串口调试、启动控制与电源动作：

| Pin 编号 | 信号名称 | 功能与硬件接法 |
| :---: | :--- | :--- |
| **1 / 2** | `PC_LED-` / `PC_LED+` | 外部状态指示灯（正负极），指示开机状态 |
| **3 / 4** | `UART0_RXD` / `UART0_TXD` | **系统 DEBUG UART0 串口**，用于输出主控内核调试 Log |
| **5 / 6** | `BMCU_ACOK` / `AUTO_ON_DIS` | **上电自启配置**：短接此二针可启用“上电自动开机”；断开则需通过按键手动开机 |
| **7 / 9 / 11**| `GND` | 电源地 |
| **8** | `PMIC_RST_OUTn` | 硬件复位引脚，短接至 GND 触发系统强制重启 |
| **10** | `FORCE_RECOVERY` | 刷机/下载按键（FEL 模式），短接至 GND 并复位可进入烧录模式 |
| **12** | `SLEEP/WAKE` | 开关机 / 休眠唤醒引脚，短接至 GND 触发电源动作 |

## 2. MIPI CSI 摄像头多链路复用配置

K3 CoM260 载板提供 2 个 22-Pin MIPI CSI 摄像头 FPC 连接器，支持非常灵活的多路并发输入。

### 2.1 链路复用机制
核心板在出厂时，可通过**板载电阻配置**，实现以下三种 MIPI CSI 通道组合：
* **“4 + 4” 模式**：CAM0 占用 4 lanes，CAM1 占用 4 lanes。适用于双路超高清图像并发输入。
* **“4 + 2 + 2” 模式**：支持三路摄像头并发。
* **“2 + 2 + 2 + 2” 模式**：支持四路摄像头并发。

### 2.2 默认出厂配置 (Default)
* **CAM0 连接器**：配置为 **2 lanes** 带宽。
* **CAM1 连接器**：配置为 **2 + 2 lanes** 或 **4 lanes** 带宽。

## 3. MIPI DSI 屏接口设计与热插拔红线

载板引出了一个 30-Pin 的 MIPI DSI 屏连接器，可完美适配树莓派标准的 4.3 英寸电容触摸显示屏（内置 I2C 触摸控制总线）：

> [!CAUTION]
> **MIPI DSI 显示接口与触控接口绝对不支持热插拔**。
> 必须在**完全断电**的状态下连接好显示屏 FPC 线缆，然后再上电开机。在带电状态下插拔屏线极易导致 DSI PHY 或者是屏幕控制 IC 发生永久性静电击穿。
