# K3 CoM260 开发套件板级硬件设计与调试专题档案

> [!TIP]
> **💡 工程师导读与排坑焦点**：详解 CoM260 核心板排针引脚复用、CSI 多路复用与 DSI 屏线热插拔避坑。
> **目标读者**：`硬件电路工程师 / 核心板开发` | **技术领域**：`hardware_schematic_design`

本专题档案汇总了基于 SpacemiT K3 芯片的核心模组 K3 CoM260 及其参考载板的硬件设计规范、12-Pin 多功能调试接口、MIPI CSI 摄像头多链路复用配置以及屏显接口避坑指南。

---

## 1. 12-Pin 多功能按键与调试接口

K3 CoM260 参考载板上设计了一个高集成度的 **12-Pin 调试与控制排针**，汇总了状态显示、串口调试、启动控制与电源动作：

| Pin 编号 | 信号名称 | 功能与硬件接法 |
| :---: | :--- | :--- |
| **1 / 2** | `PC_LED-` / `PC_LED+` | 外部状态指示灯（正负极），指示开机状态 |
| **3 / 4** | `UART0_RXD` / `UART0_TXD` | **系统 DEBUG UART0 串口**，用于输出主控内核调试 Log |
| **5 / 6** | `BMCU_ACOK` / `AUTO_ON_DIS` | **上电自启配置**：短接此二针可启用“上电自动开机”；断开则需通过按键手动开机 |
| **7 / 9 / 11**| `GND` | 电源地 |
| **8** | `PMIC_RST_OUTn` | 硬件复位引脚，短接至 GND 触发系统强制重启 |
| **10** | `FORCE_RECOVERY` | 刷机/下载按键（FEL 模式），短接至 GND 并复位可进入烧录模式 |
| **12** | `SLEEP/WAKE` | 开关机 / 休眠唤醒引脚，短接至 GND 触发电源动作 |

## 2. MIPI CSI 摄像头多链路复用配置

K3 CoM260 载板提供 2 个 22-Pin MIPI CSI 摄像头 FPC 连接器，支持非常灵活的多路并发输入。

### 2.1 链路复用机制
核心板在出厂时，可通过**板载电阻配置**，实现以下三种 MIPI CSI 通道组合：
* **“4 + 4” 模式**：CAM0 占用 4 lanes，CAM1 占用 4 lanes。适用于双路超高清图像并发输入。
* **“4 + 2 + 2” 模式**：支持三路摄像头并发。
* **“2 + 2 + 2 + 2” 模式**：支持四路摄像头并发。

### 2.2 默认出厂配置 (Default)
* **CAM0 连接器**：配置为 **2 lanes** 带宽。
* **CAM1 连接器**：配置为 **2 + 2 lanes** 或 **4 lanes** 带宽。

## 3. MIPI DSI 屏接口设计与热插拔红线

载板引出了一个 30-Pin 的 MIPI DSI 屏连接器，可完美适配树莓派标准的 4.3 英寸电容触摸显示屏（内置 I2C 触摸控制总线）：

> [!CAUTION]
> **MIPI DSI 显示接口与触控接口绝对不支持热插拔**。
> 必须在**完全断电**的状态下连接好显示屏 FPC 线缆，然后再上电开机。在带电状态下插拔屏线极易导致 DSI PHY 或者是屏幕控制 IC 发生永久性静电击穿。
