# K1 DDR 与 eMMC 兼容性验证 SOP 专题档案

> [!TIP]
> **💡 工程师导读与排坑焦点**：详解 LPDDR4x 与 eMMC 高低温环境压测、memtester/fio 指令及 SOP 判定。
> **目标读者**：`测试工程师 / 系统稳定性` | **技术领域**：`bsp_kernel_drivers`

本专题定义了进迭时空 K1 芯片平台关键器件（LPDDR4x SDRAM、eMMC 5.1 Flash）在选型及兼容性测试时的标准验证方法与判定准则。

> [!NOTE]
> 原始设计参考自 [K1 AVL兼容性验证标准操作流程（SOP）](../Sources/docs-chip/zh/key_stone/k1/k1_hw/avl_veri_sop.md)，用于指导硬件兼容性准入。

## 1. 测试环境与设备规范

进行兼容性验证时，必须严格控制测试硬件和环境温度，以确保数据的准确性和可复用性。

### 1.1 硬件设备要求
*   **验证平台**：每款待测器件至少配置 10 台 **K1 DEB1** 硬件平台作为并发测试样机。
*   **供电要求**：采用 PD 3.0 或 12V DC-IN 供电，电源功率必须 **≥ 20W**。
*   **散热要求**：所有样机必须统一配备官方指定的标准散热片。

### 1.2 严苛环境测试矩阵

根据器件的温度规格（商规/工规），必须在温箱中执行不同的温度循环：

| 规格类型 | 环境类型 | 温度与湿度条件 | 测试周期与步骤 |
| :--- | :--- | :--- | :--- |
| **商规** | 室温 (RT) | 25°C ± 3°C，0~90% RH | 常规环境测试 |
| | 低温 (LT) | -20°C，0% RH | 以 3°C/min 降温至 -20°C 并保持稳定 |
| | 高低温循环 | -20°C 至 70°C，0% RH | 1. 降温至 -20°C 保持 4 小时<br>2. 升温至 70°C 保持 4 小时<br>3. 升温/降温斜率 3°C/min，此为 1 个循环 |
| **工规** | 室温 (RT) | 25°C ± 3°C | 常规环境测试 |
| | 低温 (LT) | -40°C，0% RH | 以 3°C/min 降温至 -40°C 并保持稳定 |
| | 高低温循环 | -40°C 至 85°C，0% RH | 1. 降温至 -40°C 保持 4 小时<br>2. 升温至 85°C 保持 4 小时<br>3. 升温/降温斜率 3°C/min，此为 1 个循环 |

## 2. LPDDR4x SDRAM 兼容性验证

### 2.1 判定标准
1.  **内存压测**：多线程 `memtester` 运行期间无任何 failure 报错，系统无挂死、无错误指针复位。
2.  **低温冷启动**：在极限低温下能正常冷启动进入系统并成功登录，轻量内存读写无异常。

### 2.2 验证方法与指令

*   **常温/低温/高温压力测试**：
    在对应温度环境下，登录系统后执行 8 线程内存压测，持续运行 **24 小时**。
    ```bash
    # 计算每线程测试容量 A = (free_memory - 100M) / 8
    # 后台并发执行 8 个线程
    memtester A &
    # 重复执行共 8 次...
    ```
*   **低温冷启动测试**：
    在温箱达到目标低温后，整板**断电静置 2 小时**，然后上电启动系统并登录，运行轻量级内存测试。每次启动间隔 2 小时，**共执行 20 次**。
    ```bash
    memtester 10M 1
    ```
*   **高低温循环压力测试**：
    在系统运行 8 线程 `memtester` 的状态下，温箱按高低温循环运行，要求**完成 10 个完整循环**。

## 3. eMMC 5.1 Flash 兼容性验证

### 3.1 判定标准
1.  **读写压测**：高负载 `fio` 运行过程中无任何 CRC 校验错误，系统运行无挂死或丢盘。
2.  **镜像升级**：连续多次固件烧录过程无异常，且每次升级后均可正常引导启动。

### 3.2 验证方法与指令

*   **镜像升级测试**：
    在常温下使用量产工具对单板**连续烧录 10 次镜像**，每次烧录后均需正常上电并登录系统。
*   **常温/低温/高温读写压测**：
    在对应温度环境下，使用 `fio` 对存储进行混合读写压测，持续运行 **24 小时**（循环压测可达 48/100 小时）。
    ```bash
    # 允许用户态访问性能计数器
    echo 2 | sudo tee /proc/sys/kernel/perf_user_access
    
    # 执行 60%读 / 40%写 的随机混合读写，开启 crc32 校验
    # 测试容量建议设为 rootfs 分区可用容量的 70%
    fio -name=rand-RW -direct=1 -iodepth=64 -rw=randrw -rwmixread=60 -rwmixwrite=40 -ioengine=libaio -bs=128k -size=10G -numjobs=1 -runtime=24h -time_based -directory=/root/ -filename=fio-rand-RW --verify=crc32
    ```
*   **高低温循环读写压测**：
    在系统运行上述 `fio` 压测指令的状态下，温箱按照高低温循环模式运行，要求随温箱**完成 20 次完整循环**。
