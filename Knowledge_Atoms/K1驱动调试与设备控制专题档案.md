# K1 驱动调试与设备控制专题档案

> [!TIP]
> **💡 工程师导读与排坑焦点**：详解 PD 充电、DTS 启用 I2C、PWM 控制及 GPADC 电压采集调试方法。
> **目标读者**：`驱动工程师 / 嵌入式软件` | **技术领域**：`bsp_kernel_drivers`

本专题档案整理了 K1 芯片板级外设驱动调试、传感器/设备控制以及在 U-Boot 与 Linux 环境下进行硬件接口联调的实用方法。

---

## 1. 电源与充电管理调试

### 1.1 PD 充电状态检测
K1 单板若适配了 Type-C PD 充电（例如采用 `husb239` 芯片），可在系统启动后的串口日志中过滤检测 PD 握手状态：
```text
[57876.292256] husb239 4-0042: pd detect 
[57876.543622] husb239 4-0042: update sink voltage: 9000000 current: 3000000
```
日志中成功输出 `pd detect` 且电压/电流正常更新（如握手 9V/3A），即表明 PD 握手成功并进入 PD 快速充电模式。

### 1.2 保持 LDO 在休眠时不关闭
部分外设在系统进入挂起休眠（Suspend）时仍需持续供电。以 `ALDO2` 配置为 3.3V 常开为例，需分阶段配置设备树（DTS）：
*   **U-Boot SPL 阶段**：修改 `k1-x_spm8821.dtsi` 中对应 LDO 的参数，使能在 SPL 阶段调压且休眠不关闭：
    ```c
    &aldo2 {
        regulator-init-microvolt = <3300000>; // 初始3.3V
        regulator-boot-on;                    // 启动时开启
        u-boot,dm-spl;                        // SPL阶段使能
        regulator-state-mem {
            regulator-off-in-suspend;        // 代表休眠时不关闭该电源轨
        };
    };
    ```
*   **Linux 内核阶段**：在单板设备树（如 `k1-x_deb1.dts`）的对应 LDO 节点下添加 `regulator-always-on` 和休眠状态：
    ```c
    ldo_2: LDO_REG2 {
        regulator-boot-on;
        regulator-always-on;
        regulator-state-mem {
            regulator-off-in-suspend;               // 休眠时不关闭
            regulator-suspend-microvolt = <500000>; // 休眠时电压降至 0.5V
        };
    };
    ```

### 1.3 自定义温控保护
为了防止芯片在高负载或恶劣散热环境下烧坏，可在内核设备树中配置临界过温自动关机：
*   **修改温控设备树** `arch/riscv/boot/dts/spacemit/k1-x_thermal_cooling.dtsi`：
    在 `cls0_trip4`（CPU 簇 0）与 `cls1_trip4`（CPU 簇 1）节点中配置 `critical` 阈值（推荐最高温度为 115℃）：
    ```c
    cls0_trip4: cls0-trip-point4 {
        temperature = <115000>;   // 触发关机的温度（单位：毫度，即 115℃）
        hysteresis = <5000>;     // 温度回差（5℃）
        type = "critical";        // 临界关机类型
    };
    ```
    *(注：如无特殊需求，严禁在内核配置中关闭 `CONFIG_THERMAL` 编译选项。)*

## 2. 硬件外设接口联调

### 2.1 I2C 接口开启与读写
*   **DTS 启用 I2C**：在 U-Boot 和 Linux 的单板设备树中，将目标 I2C 控制器（如 `&i2c5`）的 `status` 属性设置为 `"okay"`，并关联正确的 `pinctrl` 配置。
*   **U-Boot 命令行读写**：
    ```c
    i2c dev 2           // 切换到总线 2
    i2c md 0x53 1 1     // 从设备地址 0x53 读取 1 字节
    i2c mw 0x53 1 0x11  // 向 0x53 寄存器 1 写入数据 0x11
    ```
*   **Linux 命令行读写**：
    ```bash
    i2cdetect -y -r 5             # 扫描总线 5 上的所有设备
    i2cdump -y 5 0x53             # 读取 0x53 设备的全部寄存器
    i2cset -f -y 5 0x53 0x1 0x11  # 向 0x53 寄存器 1 写入数据 0x11
    ```

### 2.2 PWM 通道控制 LED 闪烁
可以通过 Linux 的 `sysfs` 文件系统直接控制 PWM 引脚的占空比和频率：
1. **导出通道**（以 `pwmchip0` 的 `pwm0` 为例）：
   ```bash
   echo 0 > /sys/class/pwm/pwmchip0/export
   ```
2. **配置周期与占空比**（周期 1,000,000ns 代表 1kHz，占空比 500,000ns）：
   ```bash
   echo 1000000 > /sys/class/pwm/pwmchip0/pwm0/period
   echo 500000 > /sys/class/pwm/pwmchip0/pwm0/duty_cycle
   ```
3. **使能输出**：
   ```bash
   echo 1 > /sys/class/pwm/pwmchip0/pwm0/enable
   ```

### 2.3 GPADC 电压值获取
利用片内模拟/数字转换器（ADC）可以获取外部电池或检测点的电压值：
1. **进入 IIO 设备目录**：
   ```bash
   cd /sys/bus/iio/devices/iio:device0
   ```
2. **读取原始值与缩放比例**：
   ```bash
   cat in_voltage2_raw    # 例如输出 800
   cat in_voltage2_scale  # 例如输出 1.25
   ```
3. - **计算电压值**：将读取到的原始电压值与缩放比例相乘，得到实际电压值（单位为毫伏，mV）。
      电压值（mV）= 原始电压值 × 缩放比例。

### 2.4 命令行拉高/控制 GPIO
在软硬件联调阶段，可通过命令行直接控制 GPIO 的电平状态进行快速测试：
*   **Linux Kernel 环境**（以拉高 `GPIO 122` 为例）：
    ```bash
    echo 122 > /sys/class/gpio/export                   # 导出 GPIO
    echo out > /sys/class/gpio/gpio122/direction       # 设为输出模式
    echo 1 > /sys/class/gpio/gpio122/value             # 输出高电平 ("0" 代表低电平)
    ```
*   **U-Boot 环境**（以拉高 `GPIO 116` 为例）：
    ```c
    gpio set 116                                       # 直接拉高 (拉低用 gpio clear 116)
    ```

### 2.5 Type-C 数据角色状态检测
在 Linux 系统下，可通过 sysfs 节点快速获取当前 Type-C 接口的连接与角色状态：
```bash
cat /sys/class/typec/port0/data_role
```
*   输出为 `host [device]`：代表未连接外设，或者**作为 Device 连接到了 PC**。
*   输出为 `[host] device`：代表**作为 Host 连接了 U 盘**等外接 USB 设备。

### 2.6 自定义以太网指示灯 (LED) 状态
若需要修改板载以太网接口 LED 指示灯的闪烁/常亮行为（以 Realtek PHY 为例），可通过修改驱动程序直接配置 LED 控制寄存器 (LCR，位于扩展页 `0xd04` 地址 `0x10`)：
1.  **定义 LED 模式**（在 `drivers/net/phy/realtek.c` 中定义组合宏）：
    ```c
    #define RTL8211F_LCR        0x10
    #define LED1_ACT            BIT(9)
    #define LED1_LINK_1000      BIT(8)
    #define LED1_LINK_100       BIT(6)
    #define LED1_LINK_10        BIT(5)
    #define LED2_LINK_1000      BIT(13)
    
    // 自定义组合模式：LED1 指示所有速率的链接与 Active，LED2 仅指示千兆链接
    #define MY_LED_MODE (LED1_LINK_1000 | LED1_LINK_100 | LED1_LINK_10 | LED1_ACT | LED2_LINK_1000)
    ```
2.  **在 `rtl821x_probe` 中写入寄存器**：
    ```c
    msleep(100);
    ret = phy_write_paged(phydev, 0xd04, RTL8211F_LCR, MY_LED_MODE);
    if (ret < 0)
        return ret;
    ```
    重新编译并部署内核驱动后即可生效。
