## 1. 产品概述与核心定位

RV2768 是一款 **2U 19 英寸标准机架式 RISC-V 原生 AI 集群服务器**，专为大规模并行计算与 AI 推理工作负载设计：
*   **处理器**：搭载 **48 个** SpacemiT K3 计算节点，总计 **768 个 RISC-V 核心**。
*   **指令集规范**：符合 RISC-V 国际基金会的 **RVA23 Profile**，支持向量（Vector）和虚拟化（Hypervisor）扩展。
*   **AI 算力**：总计 **2880 TOPS @INT4** 通用 AI 运算能力。
*   **内存容量**：最大 **1536 GB** LPDDR5（每节点 32GB × 48 节点）。
*   **物理隔离**：各计算节点之间具备物理安全隔离特性，支持多租户独立管理维护。

---

## 2. 硬件架构与物理结构

### 2.1 计算模组
*   整机最多装载 **24 个计算模组**，每个模组拥有 **2 个 K3 计算节点**，可独立维护。
*   每个 K3 计算节点配备：
    *   **8 个 X100 CPU 核**（单核 SPECint2006 > 9.0/GHz，最大主频 2.4 GHz）
    *   **8 个 A100 AI 核**（提供 60 TOPS @INT4 算力）
    *   LPDDR5 RAM（8/16/32 GB 可选，最高 6400 MT/s）
    *   NVMe SSD（PCIe 3.0 x4，64/128/256 GB 可选）

### 2.2 交换系统
*   内部集成 **三层管理交换机**（216 Gbps 交换容量）。
*   对外提供 **2 × 10GE SFP+ 光口** 和 **48 × 10GE SFP+ 光口**。
*   支持 VLAN 划分、动态路由、链路聚合。

### 2.3 电源与散热
*   **电源模块**：CRPS 2000W / 3000W 白金/钛金电源，支持 **1+1 冗余热插拔**。
*   **风扇模块**：后置 4 风扇 N+1 冗余设计，支持智能调速策略。
*   **前出线 (Front I/O)** 设计：机柜后部无任何线缆，便于热通道利用与快速维护。

## 3. 系统管理与 BMC

### 3.1 基板管理控制器 (BMC)
*   支持多节点计算模组的统一管理，前出专用管理 GE 网口。
*   提供全面的故障检测、运维特性与智能散热调速。
*   支持对节点进行硬件电源管理、系统复位、固件配置、串口调试和远程桌面操控。

### 3.2 计算节点特性
*   支持 **PXE 启动**（无需本地存储，通过网络引导）。
*   支持远程访问、调试和升级。
*   支持完整的硬件虚拟化能力（CPU、内存、中断、I/O）。

## 4. Redfish API 管理接口

RV2768 提供完整的 **Redfish** RESTful API 接口用于远程管理：

### 4.1 系统命名规则
*   每个计算模组编号为 `sub<X>`，其中包含 2 个节点 `sub<X>-0` 和 `sub<X>-1`。
*   `hostId = X * 2 + Y`，用于唯一标识节点。

### 4.2 核心 API 接口

| 接口类别 | 功能 | 说明 |
| :--- | :--- | :--- |
| **电源控制** | 开机 / 关机 / 重启 / 强制断电 | 支持对单个节点的精确电源操控 |
| **CPU 资产信息** | 查询处理器型号、核心数 | 获取 K3 计算节点硬件信息 |
| **风扇模式控制 (OEM)** | 自动 / 手动调速切换 | 通过 OEM 扩展接口控制散热策略 |
| **风扇转速控制 (OEM)** | 设置 / 查询风扇转速 | 支持精确的百分比转速设定 |
| **固件升级 (OEM)** | 触发固件更新模式 | 支持远程固件批量升级 |
| **模组在位查询** | 检测已安装模组 | 查询 24 个模组插槽的在位状态 |
| **网络协议** | HTTPS 配置、SSH 控制 | 管理 BMC 网络安全设置 |

## 5. 软件平台与应用生态

*   **操作系统**：出厂可选配预装主流 Linux 操作系统。
*   **集群管理平台 (Cluster Server)**：提供节点编排与资源调度能力。
*   **分布式计算平台 (Cluster Flow)**：支持大规模并行计算任务的编排与执行。
*   **智能体集群平台 (Cluster Agent)**：面向 AI Agent 的运行与调度平台。
