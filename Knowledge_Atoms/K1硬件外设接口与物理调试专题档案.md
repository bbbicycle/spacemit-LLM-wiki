# K1 硬件外设接口与物理调试专题档案

> [!TIP]
> **💡 工程师导读与排坑焦点**：详解 K1 串口/JTAG 物理引脚定义、电平匹配与调试供电避坑原则。
> **目标读者**：`硬件调试工程师 / 嵌入式工程师` | **技术领域**：`toolchain_debug_tools`

本专题档案汇总了 K1 芯片板级硬件原理图设计、PCB 走线阻抗以及物理调试（串口/JTAG）的实用技术指导。

---

## 1. 物理调试接口设计

在进行 K1 单板调试时，串口与 JTAG 是最核心的底层通道：

### 1.1 调试串口设计
*   **物理连接**：调试串口通常设计为 3 Pin 插针（如 Muse Pi 位于 Wi-Fi 模组旁）。连接时，单板 TX 需与串口板 RX 交叉相连，RX 与 TX 交叉。
*   **电气规范**：必须采用 3.3V 电平串口线，波特率固定为 115200（底层事实参见 [[Evidence/k1_hardware_debug_parameters]]）。

### 1.2 JTAG 调试路由
K1 支持两套 JTAG 接口（通过 `JTAG_SEL` 管脚切换，参见 [[Evidence/k1_strap_pins_config]]）：
*   **PRI JTAG (主调试口)**：位于 26 Pin 插针的 7, 11, 13, 15 号引脚（分别对应 `TDI`, `TMS`, `TCK`, `TDO`），可以直接使用 J-Link 仿真器连接调试。
*   **SEC JTAG (辅助调试口)**：复用了 SD 卡槽的 CLK 与 DATA0~3 管脚。在开发板上由于封装限制通常未引出，需制作转接小板或拆除卡槽飞线进行调试。

## 2. 电源与高速信号设计避坑

### 2.1 模拟供电与磁珠隔离
*   **红线警告**：K1 各模拟 PHY 模块（如 PLL、Audio、CSI/DSI、HDMI 等）的供电磁珠**绝对不能省略**。磁珠（推荐 120Ω@100MHz）能有效隔离模拟电源与数字电源的杂讯，省略会导致信号完整性变差，甚至导致外设无法初始化。

### 2.2 闲置外设的供电原则
*   **设计规则**：即使在项目中**不用** HDMI、PCIe、MIPI CSI、MIPI DSI、eMMC 或 USB2.0 等模块，**其对应的芯片引脚电源域也必须正常供电**，不能悬空或断电。否则会引起 SoC 内部漏电或逻辑异常。

### 2.3 GPIO90 的复用机制
*   **Strap复用**：`GPIO_90` 在系统上电复位瞬间作为 `Strap 4` 采样以配置 QSPI 的工作电压（1.8V 或 3.3V，参见 [[Evidence/k1_strap_pins_config]]）。在系统启动完成后，该管脚完全可以作为普通 GPIO 使用，无需闲置。
